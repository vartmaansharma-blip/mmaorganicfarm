# Self-hosted typefaces

Fraunces and Space Grotesk remain the site's editorial and interface faces. Their original TTFs and SIL Open Font Licence notices are retained here.

The WOFF2 files contain Latin/extended-Latin characters, punctuation, currency marks and arrows used by the current site. Hindi text intentionally uses the existing system-font fallback. Fraunces retains its weight and optical-size axes; the unused SOFT and WONK axes are pinned to their original defaults (0 and 1). Space Grotesk retains its weight axis. This reduces network payload without changing the chosen appearance.

Generated with FontTools 4.60.2 and Brotli 1.2.1, using scratch tooling outside the application dependency tree. Full source fonts remain available if future translations need additional glyphs or design variants.
